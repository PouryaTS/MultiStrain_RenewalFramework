# Multi-Strain Renewal Equation Model

This repository contains C++ solvers and Python notebooks for simulating multi-strain infection dynamics with renewal equations. The analyses compare exact and approximate models and visualize incidence, susceptibility, reproduction numbers, and model errors.

See [Code_main/README.md](Code_main/README.md) for instructions to build the Python extensions, and [shared_python/README.md](shared_python/README.md) for the notebooks selected for sharing.
